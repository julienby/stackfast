Crée une nouvelle app : $ARGUMENTS (attendu : `<recette> <slug>`, ex. `php-htmx monsite`)

1. Lance `stackfast new <recette> <slug>`. Montre la sortie (dont l'adresse). Slug refusé → arrête-toi.
2. Lance `stackfast check <slug>` : doit être vert sur le gabarit. Cite la sortie.
3. Dis-moi de continuer dans l'app : `cd apps/<slug> && claude`, puis `/prd`. Le travail sur le code de l'app se fait là, pas ici.
