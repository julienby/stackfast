3. Ouvre `apps/<stack>/<slug>/PRD.md` : pose-moi les questions des sections vides, une par une. Ne remplis rien en silence.
4. Une fois le PRD rempli, suis « Première session » de l'`AGENTS.md` de l'app. Aucune feature avant.
